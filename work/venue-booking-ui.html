Venue Booking Platform – UI Design

Interface design for a web app where people browse event venues, with a separate admin panel for managing venues.

Role
UI design, front-end development
Status
In development
Stack
React, Vite, Emotion, Material UI
Type
Personal project

01 Overview

About this project

This is a product I'm designing and building myself. This page focuses only on the visual and interface design: the screens, the mobile layout, the colour palette and the typography.

The interface is built in React, with styling written as Emotion styled components on top of a customised Material UI theme.

The interface copy is in Serbian, as the product is designed for users in Serbia.

02 Design system

Colour & type
